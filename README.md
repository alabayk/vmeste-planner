# Вместе

PWA-планер для двух пользователей: личные пространства, общий план, офлайн-кэш и живые обновления.

## Запуск

1. Создать PostgreSQL и выполнить `schema.sql`.
2. Задать секретную переменную `DATABASE_URL`.
3. Выполнить `npm install && npm start`.

## alwaysdata

Node.js-сайт запускается командой `node /home/ACCOUNT/www/vmeste/server.js`. `DATABASE_URL` и доступы хранятся только в панели alwaysdata, никогда в публичном репозитории.
